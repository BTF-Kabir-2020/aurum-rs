# Release

## Versioning

- Start: `0.1.0`
- Semantic versioning
- Expose `aurum version` and an API version field in responses

## Release workflow

`.github/workflows/release.yml` is **generated by cargo-dist** (`dist generate`)
and triggers on tag `v*`. It builds archives + installers for the target matrix
and creates the GitHub release. Runs in the **`production` GitHub Environment** —
create it in repo settings (Settings → Environments) before the first tag.

## Packaging tool: cargo-dist (ACTIVE — initialized 2026-09-21, v0.32.0)

- Config: `dist-workspace.toml` (`ci = "github"`, installers = shell + powershell).
- Regeneration: edit config → `dist generate`. Never hand-edit the generated `release.yml`.
- Local pre-flight: `dist plan`.
- Targets (README §16): x86_64-pc-windows-msvc, x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu, x86_64-apple-darwin, aarch64-apple-darwin.

Supported targets (at minimum Windows and Linux):

| Target | Notes |
|---|---|
| Windows x86_64 | required |
| Linux x86_64 | required |
| Linux ARM64 | configured |
| macOS x86_64 | configured |
| macOS ARM64 | configured |

The release system generates installers:

- `install.ps1` (Windows)
- `install.sh` (Linux/macOS)

People who grab a published release get a ready binary. Compiling Rust is **not** required.

## Developers

```
cargo install --path .
```

## CI / release workflow

- `.github/workflows/ci.yml`: fmt, check, clippy, test on every push/PR.
- `.github/workflows/release.yml`: builds binaries for the supported targets and publishes GitHub release artifacts via cargo-dist.
- Native release artifacts do not require Docker.

## Release checklist before tagging

- [x] `cargo fmt --all -- --check` passes
- [x] `cargo check --all-targets --all-features` passes
- [x] `cargo clippy --all-targets --all-features -- -D warnings` passes
- [x] `cargo test --all-targets --all-features` passes
- [x] `aurum version` output matches the tag
- [x] Demo, doctor, API, backup/restore, Docker smoke tests pass
- [x] No secrets committed
- [x] README/docs updated
