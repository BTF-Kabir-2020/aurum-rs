# cli

Clap-based command-line interface.

- `demo.rs` — offline deterministic demo (speeds, screenshot-friendly)
- `doctor.rs` — diagnostics
- `config.rs` — config show / validate / init
- `market.rs` — quote / signal / history / watch
- `backup.rs` — backup create / verify / restore

Root commands also include `init`, `server`, and `version`.
